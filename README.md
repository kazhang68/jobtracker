# Job Track

A private, full-stack job application tracker with a compact dark interface.

## Features

- Track companies, roles, locations, and job-description links
- Record application stages and update dates
- Compare listed compensation with Levels.fyi estimates
- Capture remote/flexible work details, contacts, notes, pros, and cons
- Schedule and filter follow-up actions
- Persist application data with Cloudflare D1

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Validate a production build with:

```bash
npm test
npm run lint
```
